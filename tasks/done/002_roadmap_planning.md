# План развития (Roadmap) - Florist ERP

## Ближайшие задачи

### 1. Модуль Инвентаризации (Inventory)
- [ ] Расширенное управление партиями (Batch management).
- [ ] Учет списаний и брака (Spoilage/Waste).
- [ ] Автоматический расчет себестоимости.

### 2. Модуль Заказов и Продаж (Ordering)
- [ ] Создание заказа с интеграцией рецептов.
- [ ] Статусная модель заказа.
- [ ] Интеграция с платежными ссылками.

### 3. Storefront API
- [ ] Эндпоинт каталога (интеграция с остатками и рецептами).
- [ ] Эндпоинт оформления заказа для витрины.

### 4. Фронтенд (VueJS)
- [ ] Настройка каркаса приложения.
- [ ] Дашборд администратора.
- [ ] Управление рецептами и остатками через UI.

### 5. Инфраструктура
- [ ] Docker-compose для быстрой развертки.
- [ ] Базовая авторизация.

---
*Этот план является динамическим и может дополняться по мере реализации.*
